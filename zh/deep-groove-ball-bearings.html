深沟球轴承

产品 · 深沟球轴承

深沟球轴承是应用最广泛的滚动轴承：结构简单、摩擦低、极限转速高，可承受径向载荷及一定的双向轴向载荷。防尘盖（Z / ZZ）与密封圈（RS / 2RS）型号终身润滑，免维护。

尺寸范围内径 d 10–40 mm · 外径 D 28–100 mm · 宽度 B 8–25 mm（本页所列尺寸范围；其他尺寸可订货）
型号覆盖型号按您的图纸或样品确认；本页所列尺寸按 d / D / B 对应，非标尺寸也可提供
精度等级标准 P0；P6 / P5 可订货（精密型号可达 P4）
游隙组C0 / C2 / C3 / C4（按应用选定）
材料GCr15 高碳铬钢 / 渗碳钢（可选）
保持架冲压钢 / 黄铜 / 聚酰胺（按类型与工况）
热处理调质处理，58–64 HRC，尺寸稳定化
标准GB/T 307 / ISO 492（适用者）
获取报价 WhatsApp
要点：
  • 通用性强：摩擦低、噪声低、极限转速高
  • 可承受径向载荷及双向轴向载荷
  • 开式 / 防尘盖（Z、ZZ）/ 密封圈（RS、2RS）结构
  • 预填润滑脂，适用于免维护的轻中载工况

FAQ

该类轴承常见问题

深沟球轴承可提供哪些尺寸？

本页所列尺寸覆盖内径 d 10–40 mm · 外径 D 28–100 mm · 宽度 B 8–25 mm（本页所列尺寸范围；其他尺寸可订货）。更大与中间尺寸按图纸制造——请发送 d / D / B 与载荷工况，我们会书面确认可供性。

能否提供 P6 或 P5 精度等级？

标准 P0；P6 / P5 可订货（精密型号可达 P4）。请在图纸上注明所需等级，我们会单独列项报价。

是否接受非标与小批量订单？

可以。样品订单 1 件起，非标轴承按图纸或样品制造；价格、交期与付款条件在付款前书面确认。
