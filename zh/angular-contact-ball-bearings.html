角接触球轴承

产品 · 角接触球轴承

角接触球轴承滚道与球之间有接触角，可同时承受径向与轴向载荷。常见接触角为 15°、25° 与 40°——角度越大，轴向承载越高。单列型号承受单向轴向载荷，通常成对或成组安装；四点接触型号可承受双向轴向载荷；双列型号的性能相当于一对背对背安装的轴承。

尺寸范围内径 d 10–130 mm · 外径 D 30–260 mm · 宽度 B 14–65.1 mm（本页所列尺寸范围；其他尺寸可订货）
型号覆盖本站已列出 70 个型号（含内径变型），例如 116124、116320、……、QJF322；其他型号按图纸或样品制造
精度等级标准 P0；P6 / P5 可订货（精密型号可达 P4）
游隙组C0 / C2 / C3 / C4（按应用选定）
材料GCr15 高碳铬钢 / 渗碳钢（可选）
保持架冲压钢 / 黄铜 / 聚酰胺（按类型与工况）
热处理调质处理，58–64 HRC，尺寸稳定化
标准GB/T 307 / ISO 492（适用者）

  • 可承受径向与轴向联合载荷；接触角 15° / 25° / 40°
  • 单列型号可按 DB（背对背）、DF（面对面）或 DT（串联）成对安装
  • 四点接触型号一个轴承即可承受双向轴向载荷
  • 双列型号刚性好，可承受倾覆力矩

角接触球轴承可提供哪些尺寸？

本页所列尺寸覆盖内径 d 10–130 mm · 外径 D 30–260 mm · 宽度 B 14–65.1 mm（本页所列尺寸范围；其他尺寸可订货）。更大与中间尺寸按图纸制造——请发送 d / D / B 与载荷工况，我们会书面确认可供性。
